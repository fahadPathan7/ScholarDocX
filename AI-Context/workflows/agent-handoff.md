# Agent Handoff

Use this file to keep AI work continuous across sessions.

## Handoff Principles

- Leave durable state in files, not only in chat.
- Keep task status current.
- Record why decisions were made.
- Keep context compact.
- Link files instead of repeating large sections.

## What To Update At End Of A Task

In the active Jira task:

- Status
- Changed files
- Verification completed
- Known limitations
- Follow-up tasks

In context files:

- New requirements
- Changed workflows
- New technical decisions
- Updated project structure

## What Not To Do

- Do not leave important decisions only in final chat messages.
- Do not bury feature requirements inside code comments.
- Do not add broad undocumented abstractions.
- Do not let one file become the whole project brain.
