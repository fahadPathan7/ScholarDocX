# ScholarDock Handoff

## End Of Task

Update the active Jira task with:

- Status.
- Changed files.
- Verification commands and outcomes.
- Unit tests added, updated, or intentionally skipped.
- Important decisions.
- Known limitations.
- Follow-ups.

## Context Check

Confirm context still matches implementation:

- Business context if scope, value, privacy, cost, or personas changed.
- Functional context if user-visible behavior changed.
- Technical context if architecture, APIs, storage, integrations, security, tests, or structure changed.

## Final Response

Tell the user what changed, how it was verified, and any limitations. Keep it short and concrete.
