## Plan: Organize Tests into unit/regression/smoke + Add Corner-Case Coverage

### Problem
30 backend test files sit flat in `backend/tests/` with no category structure. Markers exist but only 12 tests are tagged. Several pure-logic modules have zero or near-zero coverage with untested edge cases (including two latent bugs).

### Approach
1. **Reorg files into folders** by dominant purpose.
2. **Extract shared helpers** to fix the one cross-test import blocker.
3. **Add ~50 focused corner-case tests** across 5 high-value modules.
4. Keep markers AND folders in sync (folder = category; marker = runnable subset).

---

### Part 1: Folder Reorg (move 30 files → 3 folders)

**New structure:**
```
backend/tests/
├── conftest.py              ← STAYS HERE (parents[1] sys.path setup)
├── helpers.py               ← NEW: extracted make_settings/make_user/get_balance
├── unit/                    ← 23 files (service/API logic)
├── regression/              ← 2 files (known-bug guards)
└── smoke/                   ← 3 files (core-path boot checks)
```

**Categorization (by dominant purpose):**

| Folder | Files |
|--------|-------|
| `smoke/` | `test_workspace.py`, `test_store.py`, `test_auth_password.py` (the 3 files with smoke-tagged tests) |
| `regression/` | `test_api_auth.py` (5 regression tags + IDOR/security guards), `test_limits_billing_guards.py` (docstring: "Regression tests for SCHOLARDOCX-0111") |
| `unit/` | All other 25 files (services, API, persistence, AI, news, scholarship, advisor atlas, etc.) |

**Mixed-file handling:** Files with a mix (e.g. `test_store.py` = 2 smoke + 13 unit) go to their **dominant** folder. The markers still let you run just the smoke subset via `make smoke`. This avoids splitting test files (riskier, more churn).

**The `__init__.py` decision:** Add `__init__.py` to each subfolder so pytest treats them as packages and the cross-folder helper imports resolve cleanly. (The root `tests/` stays package-less as today.)

---

### Part 2: Fix the cross-test import blocker

**Problem:** `test_openrouter_cost.py:6` does `from test_ai_tokens import make_settings, make_user, get_balance` — breaks when files move to different folders.

**Fix:** Extract `make_settings`, `make_user`, `get_balance`, `set_model_price`, `ledger_rows` into `backend/tests/helpers.py`. Update `test_openrouter_cost.py` and `test_ai_tokens.py` to import from `helpers` instead. This is the minimal change to unblock the move. (The other 14 files that duplicate these helpers locally are left as-is — out of scope for this task; they're self-contained.)

### Part 3: Corner-Case Tests (~50 new tests across 5 modules)

**Backend (4 new files in `unit/`):**

1. **`unit/test_categories.py`** (~8 tests) — `normalize_media_category`: empty/whitespace/None raises ValueError, unicode, 80-char truncation, special-chars-only. `category_display_name`: empty/None/whitespace fallback, normal strip.

2. **`unit/test_analysis_helpers.py`** (~10 tests) — `extract_json_object`: empty string, no braces, array (not dict), nested, multi-object latent bug, text-wrapped. `tokenize`: empty, all-stopwords, 2-char minimum boundary, 3-char inclusion, `c++`/`machine-learning` token rules.

3. **`unit/test_intelligence_helpers.py`** (~10 tests) — `upcoming_semesters`: count=0, count cap, Jan/Aug/July/Dec month boundaries. `normalize`: unicode dropping, special chars. `concept_family`: empty, no-match, computing match, multi-word.

4. **`unit/test_jwt_edge_cases.py`** (~6 tests) — `decode_token`: empty string, wrong secret, None. `verify_token_version`: both-missing (`None == None` → True silent pass), payload-only. `create_token`: zero expiration days.

**Frontend (2 new files):**

5. **`frontend/src/lib/__tests__/date.test.ts`** (~8 tests) — `parseLocalDate`: empty/null/undefined → null, invalid string → null, `"2026-13-45"` rollover bug (document current behavior), ISO regex path. `formatShortDate`/`formatLongDate`: null fallbacks, valid date format.

6. **`frontend/src/lib/__tests__/accessErrors.test.ts`** (~8 tests) — `buildAccessErrorDetail`: 429 rate, 403 limit/permission/general branches, non-403 → null, empty message → null. `toFeatureLabel`: known/unknown/undefined. `extractFeature`: regex patterns.

**Bug handling:** Two latent bugs were found (`extract_json_object` multi-object returns None; `parseLocalDate` invalid-date rollover). Tests will **document current behavior** (not fail the suite) with a comment noting the bug, recorded as a follow-up — fixing them is out of scope for this reorg task.
