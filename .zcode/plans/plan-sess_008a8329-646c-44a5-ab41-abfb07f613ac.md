## Goal
Replace the "Yearly" billing cycle with a "Quarterly" one across ScholarDocX. Prices and AI credits stay the same; only the name, the date-window math, and the period suffix change.

Decisions locked with you:
- **Full rename** of DB keys (`plan_price_*_yearly` → `plan_price_*_quarterly`) and stored values (`billing_cycle='yearly'` → `'quarterly'`).
- **Quarter = 90 days**, suffix **`/ qtr`** (landing page: `/ quarter`).

### `backend/app/db/connection.py` — `initialize_database()` (after line 125)
Add a small idempotent migration block that runs every init (safe — prior art at line 125 deletes `jwt_secret_key`):
1. `DELETE FROM app_settings WHERE key IN ('plan_price_general_yearly','plan_price_pro_yearly','plan_price_max_yearly')` — removes the legacy keys so admins don't see stray entries.
2. `UPDATE plan_upgrade_requests SET billing_cycle = 'quarterly' WHERE billing_cycle = 'yearly'` — backfills stored request rows.
